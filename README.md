Entry for the [One Line, Best Line](https://make.fun/bounty/u-gudril-cool-one-line-best-line-b8c41f4d) bounty on make.fun.

## The line

> My plants died while I was on a wellness retreat learning to take better care of living things.

## How it was chosen

Twelve original one-line candidates were written in this session and scored
pairwise against the contest's published judge brief: really one line on a free
and entertaining theme, stops the scroll in the first few words, genuinely
entertaining, lands in a single sentence with a turn at the end, and feels
fresh. The winner went through a second revision pass to tighten the wording
("learning to take better care" instead of "learning how to take better care").
The full tournament is in `../variants.md`.

`main.py` (standard library only) validates the line against the contest gate —
UTF-8, 1–240 characters, a single line — then writes it atomically to
`entry.txt` inside `MAKEFUN_OUTPUT_DIR` and reads it back to confirm.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
